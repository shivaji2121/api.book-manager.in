# Book Manager Application

A modern, responsive book management application built with React, Vite, and Tailwind CSS.

## Features

- 📚 **Book Management**: Add, edit, and delete books in your personal collection
- 🔐 **User Authentication**: Secure login and signup functionality
- 🎨 **Enhanced UI**: Beautiful, colorful interface with gradient accents and card-based layouts
- 📱 **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- ⚡ **Fast Performance**: Built with Vite for lightning-fast development and production builds

## Tech Stack

- **Frontend**: React + Vite + Tailwind CSS
- **UI Components**: Shadcn-inspired components with enhanced styling
- **State Management**: React Context API
- **Routing**: React Router
- **Notifications**: React Toastify
- **Icons**: Lucide React

## Key Enhancements

This version includes significant UI/UX improvements:

- **Colorful Design**: Implemented gradient accents throughout the application
- **Card-Based Layouts**: All content is presented in visually appealing cards
- **Professional Styling**: Enhanced buttons, inputs, and form elements
- **Smooth Animations**: Added transitions and hover effects for better user experience
- **Consistent Theme**: Unified color scheme with primary and accent colors

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

## Folder Structure

```
src/
├── components/     # Reusable UI components
├── context/        # React context providers
├── lib/            # Utility functions
├── pages/          # Page components
└── App.jsx         # Main application component
```
